# ADR 0004：以浏览器流程验证完整功能

## 状态

已确认

## 背景

仓库起始状态只有文档，没有前端工程、测试框架或既有测试先例。联调目标是验证真实用户流程而不是内部实现细节。

## 决策

- 浏览器端到端流程作为最高测试切面。
- 至少覆盖登录、改密、CSRF、角色菜单、401/403、产品、分类、媒体、客服和后台账号的主要页面。
- 构建、类型检查和主要页面冒烟作为交付质量门禁。
- 真实联调前后端的联通性由当前运行环境决定，不使用长期 Mock 双轨实现。

## 理由

浏览器流程能同时验证路由、表单、权限、Cookie、错误反馈和后端契约，比低层实现测试更贴近用户可观察行为。

## 后果

- 真实后端未启动时无法完成端到端联调。
- 后续若自动化覆盖扩展，应优先复用浏览器流程而不是另建大量接口单元测试。
