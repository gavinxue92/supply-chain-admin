# ADR 0001：采用 Vue 3 构建运营管理端

## 状态

已确认

## 背景

项目需要在小型供应链后端之上交付可维护的中文运营管理界面，并支持登录、产品、分类、媒体、客服和账号管理。

## 决策

- 使用 Vue 3、Vite、TypeScript、Element Plus、Pinia 和 Axios。
- 使用组合式 API 和单文件组件组织页面。
- 页面负责布局和交互组合，复杂表格、表单和动态列表拆分为独立模块。
- 后端 DTO 和 VO 使用严格的 TypeScript 接口表达，禁止引入全局 `any`。

## 理由

该技术栈与仓库现有约束一致，可覆盖后台表单、表格、对话框、状态管理和统一 HTTP 请求需求，同时保持工程体积和学习成本可控。

## 后果

- 前端需维护稳定的模块边界和类型定义。
- Element Plus 的组件能力可显著减少后台重复控件实现。
- 部署和联调配置必须配合同源代理和后端 CORS 策略。
