# ADR 0003：同源代理 API 并直传对象存储

## 状态

已确认

## 背景

前端需要避免跨域 Cookie 问题，并完成媒体授权、对象存储直传和确认登记流程。

## 决策

- 开发与生产环境均通过同源反向代理暴露后端 `/api/v1`。
- 浏览器只使用相对 `/api/v1` 地址，不在业务代码中散布后端域名。
- 媒体上传分为授权、对象存储直传和确认三个阶段。
- 每张文件只允许 JPEG、PNG 和 WebP，大小不得超过 10 MiB。
- 上传凭证过期或直传失败时重新申请凭证。
- 只有确认成功的媒体 ID 可用于产品和客服表单。

## 理由

同源代理简化 Cookie、CSRF 和 CORS 配置；对象存储直传避免管理业务 API 承担大文件上传负载。

## 后果

- 开发代理和生产反向代理配置需要保持一致。
- 页面需处理凭证失效、上传失败、确认失败和缺少已确认媒体的情况。
- 媒体公开 URL 与后台管理凭证不能混用或持久化。
