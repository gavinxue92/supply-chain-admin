# 04: 客服与后台账号管理闭环

**What to build:** 为管理员交付全局客服、产品客服策略和后台账号管理闭环，使管理员能安全配置客服入口并为运营编辑创建和维护账号。

**Blocked by:** 01: 工程、认证与角色壳

**Status:** ready-for-agent

- [ ] 管理员可读取和保存全局客服；未配置时提供明确空状态。
- [ ] 保存全局客服时至少填写微信号或已确认二维码媒体，并保留后端校验错误。
- [ ] 产品可选择继承全局客服、覆盖全局客服或关闭客服入口。
- [ ] 产品覆盖客服时至少填写微信号或已确认二维码；非覆盖策略时不提交无关客服字段。
- [ ] 后台账号列表展示用户名、角色、启用状态和改密状态；当前角色无权访问时提供 403 明确反馈。
- [ ] 管理员可创建 `EDITOR` 账号，并校验用户名和临时密码规则。
- [ ] 创建或重置临时密码成功后，一次性弹窗展示密码并提供复制按钮，不持久化到表单或日志。
- [ ] 管理员可重置账号临时密码并执行二次确认，成功后目标账号需强制改密。
- [ ] 管理员可停用账号并执行二次确认，停用后目标账号会话失效且不能继续操作。
