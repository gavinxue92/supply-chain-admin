# 03: 媒体与产品管理闭环

**What to build:** 为运营人员交付从媒体上传到产品维护的完整闭环，包括安全富文本、规格、主图、轮播图、草稿保存和产品状态流转。

**Blocked by:** 01: 工程、认证与角色壳

**Status:** ready-for-agent

- [x] 媒体上传按授权、对象存储直传、确认三个阶段完成，并遵循当前 CSRF 和 Cookie 约束。
- [x] 媒体只允许 JPEG、PNG、WebP，单文件不超过 10 MiB；失败和凭证过期时可重试或重新申请。
- [x] 产品主图只能选择一张，轮播图最多选择八张，详情图和客服二维码只能引用已确认媒体。
- [x] 富文本只提供段落、换行、标题、列表、粗体、斜体和已确认图片能力，不允许外部图片、任意 CSS、脚本或 iframe。
- [x] 产品列表展示后端原始顺序和草稿、已上架、已下架、已归档状态，不新增后端未支持的筛选排序。
- [x] 可创建草稿并编辑名称、启用末级分类、详情、关键词、排序、规格、主图和轮播图。
- [x] 产品保存提交完整替换内容；校验失败时保留用户输入并展示可操作反馈。
- [x] 可上架、下架、归档和恢复产品，并仅展示后端允许的状态操作。
- [x] 上架、下架、归档、恢复均使用二次确认；归档和恢复操作具有明确警示文案。
- [x] 保存已上架产品后立即反映后端生效状态，不展示不存在的额外发布版本。
