# 02: 分类管理闭环

**What to build:** 为运营人员交付完整的分类管理体验，包括查看、创建、编辑、启停和删除，使分类结构始终保持最多两级且错误操作能得到可操作反馈。

**Blocked by:** 01: 工程、认证与角色壳

**Status:** ready-for-agent

- [ ] 列表展示后端完整分类数组的名称、父级、启用状态和排序，不引入后端未支持的分页或筛选。
- [ ] 可创建一级分类和二级分类，并在界面中约束最多两级。
- [ ] 可编辑名称、父分类和排序；同父级下名称冲突或必填项错误时保留表单并提示。
- [ ] 可启用或停用分类，并明确提示停用一级分类会隐藏整棵分类树。
- [ ] 启停操作有成功反馈；失败时保留当前状态并展示可操作错误。
- [ ] 删除未被子分类或产品关联的分类时可成功执行并刷新列表。
- [ ] 删除遇到后端 409 冲突时引导用户停用分类，而不是只显示通用错误。
- [ ] 危险操作执行二次确认，取消时不发起写请求。
