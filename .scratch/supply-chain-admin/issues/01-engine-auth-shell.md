# 01: 工程、认证与角色壳

**What to build:** 在仓库根目录交付可运行、可构建的中文运营管理壳，并完成登录、改密、退出、CSRF、角色导航和会话恢复兜底，使用户能安全进入并使用对应权限的后台。

**Blocked by:** None (can start immediately).

**Status:** done

- [x] 根目录可安装依赖、启动开发服务、构建生产版本并通过 TypeScript 类型检查。
- [x] 页面提供左侧模块导航、顶部用户区、面包屑和中文登录界面。
- [x] 前端统一携带 Cookie、注入 CSRF token，并通过同源相对地址访问后端。
- [x] `ADMIN` 和 `EDITOR` 登录后只显示各自有权访问的菜单和路由入口。
- [x] 首次登录或重置密码后的改密流程成功后要求重新登录。
- [x] 401 清除前端登录态并跳转登录页，403 展示权限或改密提示且不无限重试。
- [x] 退出成功后清除登录态并返回登录页。
- [x] 后端未提供会话恢复接口时，刷新页面明确回到重新登录流程；接口可用后可恢复用户和角色。
